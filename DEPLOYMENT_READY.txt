                        SECURITY FEATURES
================================================================================

✅ Password Security
   - SHA256 pre-hashing + bcrypt
   - Supports passwords of any length
   - 12-round bcrypt hashing

✅ Authentication
   - JWT tokens (60 min access, 7 days refresh)
   - Two-factor authentication (TOTP)
   - Account lockout after 5 failed attempts

✅ Authorization
   - Role-based access control (RBAC)
   - Module-level permissions
   - Co-owner protection (cannot be deleted)

✅ Data Protection
   - Soft deletes (is_deleted flag)
   - Audit logging (user_log table)
   - Input validation (PAN, GSTIN, Email, Phone)
   - SQL injection prevention (parameterized queries)
